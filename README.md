# sql-retail-data-warehouse
End-to-end retail data warehouse project using SQL Server, featuring ETL, data cleaning, transformation, and analytics using the Bronze, Silver, and Gold medallion architecture.

This project demonstrates the development of an end-to-end retail data warehouse using SQL Server. The project simulates a real-world business environment where data comes from different operational systems such as CRM and ERP, requiring data cleaning, transformation, validation, and integration before it can be used for analytics.

The data warehouse follows the Medallion Architecture, consisting of Bronze, Silver, and Gold layers.

🎯 Project Objectives
Build a structured retail data warehouse using SQL Server
Ingest raw data from CRM and ERP source systems
Clean and standardize inconsistent data
Identify and handle duplicate and invalid records
Integrate data from multiple sources
Create analytical-ready datasets
Apply data quality checks and validation
Generate business insights from the transformed data
